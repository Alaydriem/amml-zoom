# Alaydriem's Zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A clean-room LeviLamina client mod that zooms the camera with a smooth, comfortable ease while a key (default tilde) is held, and slows mouse look to match.

**Architecture:** All logic lives in the Rust crate `zoom-core` (config, ease state machine, FOV and turn-scale math). `zoom-ffi` is the only `unsafe` crate and exposes a small `lz_*` C ABI with a cbindgen header. A thin C++ shim hooks `LevelRendererPlayer::getFov`, `LocalPlayer::_applyTurnDelta`, focus loss and dimension change, forwards key and world-exit events, and returns what Rust computes.

**Tech Stack:** Rust 1.98.0 (edition 2024), serde / serde_json, thiserror, log, cargo-nextest, Criterion 0.8.2, cbindgen 0.29.2, xmake 3.1.1, clang-cl, LeviLamina 26.51.6 (client), levibuildscript 0.6.2, mise.

**Spec:** `docs/superpowers/specs/2026-10-19-levi-zoom-design.md`

- All builds and tests run through `mise run <task>`. Never pipe a build or test command into `grep`/`head`/`tail`/`awk`.
- **No commits.** Each task ends at a test checkpoint. The user reviews and commits.
- Clean-room: read only `../levi-freecam`, `../levi-minimap`, first-party LiteLDev material, and docs. Never open third-party zoom or client mod source (Zoomidy, LaminaView, ZoomIntoBedrock, Flarial, Latite, VidereLonge, Bedrock-Zoom, FastMiner), including links in `docs/findings/levilamina-client-research/findings.md`.
- Names: mod / folder / xmake target `alaydriem-zoom`; display name "Alaydriem's Zoom"; author "Alaydriem"; tooth `github.com/alaydriem/levi-zoom`; crates `zoom-core`, `zoom-ffi`, `zoom-bench` under `zoom/`; C prefix `lz_`; type prefix `Lz`; header `shim/include/levi_zoom.h`; C++ namespace `levi_zoom`.
- Target: Minecraft Bedrock client 26.51.1, LeviLamina client `>=26.51.6 <26.52.0` (xmake pin `levilamina 26.51.6`, same as the siblings).
- The scroll wheel is never touched: the shim registers no `MouseInputEvent` listener (unless Task 8 is triggered, and then wheel events are skipped).
- Key events are never cancelled.

## Review Focus

1. **Key released while in a menu.** The user holds tilde, opens chat, releases tilde in chat, closes chat: the zoom must not come back. (Task 3: `release_while_out_of_gameplay_clears_hold`.)
2. **Broken config values.** `zoomFactor` of 0, negative, NaN or 1e9, negative durations, unknown easing name: the mod must still load with sane values and log a warning; NaN must never reach the FOV. (Task 1: `sanitize_*` tests.)
3. **Odd base FOV from the game.** `getFov` returns 0, a negative number or NaN (for example during a loading screen): `lz_fov` must return the input unchanged and never NaN or 0. (Task 4: `fov_passes_through_invalid_base`.)
4. **Out-of-order time.** Two threads read the clock and then wait on the lock, so a call can arrive with a slightly earlier time than the last one: the level must clamp, not go negative or jump. (Task 2: `level_before_start_is_from`.)
5. **Zoom pressed before the first frame.** The key is pressed before any `getFov` call, so there is no known base FOV yet: `turn_scale` must use a 70° default, not divide by zero. (Task 4: `turn_scale_before_first_fov_uses_default_base`.)

### Task 4: FOV and turn-scale math

**Files:**
- Create: `zoom/core/src/services/zoom_math.rs`, `zoom/core/src/structs/zoom/fov_query.rs`
- Modify: `zoom/core/src/services/zoom_controller.rs`
- Test: `zoom/core/tests/services/zoom_math.rs`, add to `zoom/core/tests/services/zoom_controller.rs`

**Interfaces:**
- Produces:
  - `FovQuery { pub normal_fov: f32, pub steady_fov: f32, pub in_gameplay: bool }` (Copy). `normal_fov` is the game's FOV with sprint and effect changes; `steady_fov` is without them.
  - `ZoomMath::zoomed_fov(base_fov: f32, zoom_factor: f32, level: f32) -> f32` = `base_fov / zoom_factor.powf(level)` (log-space interpolation).
  - `ZoomMath::blended_base(normal_fov: f32, steady_fov: f32, level: f32, fade: bool) -> f32` = `normal + (steady - normal) * level` when `fade`, else `normal`.
  - `ZoomMath::turn_scale(base_fov: f32, zoomed_fov: f32, strength: f32) -> f32` = `1 + strength * (tan(zoomed/2) / tan(base/2) - 1)` (degrees in, radians inside).
  - `ZoomController::fov(&mut self, query: FovQuery, now_us: u64) -> f32`:
    - if `normal_fov` is not finite or `<= 0` or `>= 180`: return `normal_fov` unchanged and change nothing;
    - a non-finite `steady_fov` is replaced by `normal_fov`;
    - if `!query.in_gameplay` and held: same as a release (ease out);
    - store the blended base as the last base FOV; return `zoomed_fov(base, factor, level(now))`;
    - on the first call ever, `info!` once: `"getFov hook active"`.
  - `ZoomController::turn_scale(&mut self, now_us: u64) -> f32`: uses the last base FOV (70.0 before any `fov` call) and the current level; returns exactly 1.0 when level is 0; on the first call ever, `info!` once: `"turn delta hook active"`.
